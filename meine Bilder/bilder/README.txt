MEINE BILDER

Lege deine Fotos einfach in diesen Ordner.
Du musst NICHTS in bilder.json eintragen.

Unterstützte Formate:
JPG, JPEG, PNG, GIF, WebP, AVIF

Wenn das Repository auf GitHub liegt, erstellt GitHub Actions die
Galerie-Liste automatisch. Nach dem Upload der Bilder kann es kurz
dauern, bis die Galerie aktualisiert ist.
